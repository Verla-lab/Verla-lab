# Verla Lab

Open-source scrapers and reproducible tutorials for collecting public web data with Python.

Each project focuses on one website or dataset and includes runnable code, structured JSON/CSV output, fixtures, and clear usage boundaries.

## What you will find here

- Website-specific Python scrapers
- Public product, market, app, article, and sports data examples
- JSON and CSV export workflows
- Browser automation and request-based implementations
- Tests, fixtures, sample output, and maintenance notes

## Project directory

The growing catalog is maintained in [`open-web-data-scrapers`](https://github.com/Verla-lab/open-web-data-scrapers).

## Principles

- Public or explicitly authorized data only
- No login, account creation, private data, or irreversible actions
- Respect site terms, robots guidance, rate limits, and applicable law
- Stop cleanly when access requires verification or human review
- Every repository should remain useful without a paid service

Projects are educational examples, not endorsements of or official integrations with the referenced websites.
